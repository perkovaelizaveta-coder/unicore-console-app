# UniCore 🎓

**UniCore** — це консольна система обліку студентів та викладачів, розроблена на Python. Проєкт створено з метою розробки архітектури для переходу від паперових журналів до зручного цифрового рішення.

## 🛠 Технології
* **Мова:** Python
* **Інструменти:** AI-асистенти для оптимізації логіки коду та тестування

## 🌟 Ключові можливості
* Облік даних студентів та викладачів.
* Консольний інтерфейс для швидкого доступу до записів.
* (Додай сюди ще 1-2 функції, які вміє робити твоя програма, наприклад: виведення списку груп, додавання оцінок тощо).

## 🚀 Про розробку
Цей проєкт створювався у команді з двох осіб. Моєю основною роллю був архітектурний дизайн системи, керування робочим процесом, розподіл завдань та реалізація функціонального прототипу.
